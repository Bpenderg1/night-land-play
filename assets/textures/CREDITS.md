# Texture credits

All textures here come from Poly Haven (polyhaven.com) and are CC0, free to use for anything with no credit required. Downloaded 2026-11-13 at 1k resolution.

- rocky_terrain_02: the ground of the dark plain
- castle_brick_07: the Redoubt's walls
- metal_plate: the Night-Walker's gear

Each set has a color map (diff), a surface-bump map (nor_gl, OpenGL style), a roughness map (rough) and a shadowing map (ao).
